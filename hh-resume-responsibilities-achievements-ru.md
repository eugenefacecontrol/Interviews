# Обязанности и достижения для HH.ru

## Definely — QA Automation Engineer

Писал и поддерживал автотесты для сложного продукта: API-тесты, UI-автоматизация, тестовые данные, разбор падений в CI/CD.

**Обязанности:**
- разрабатывал автотесты для API и UI на TypeScript и Playwright;
- переписывал существующий API-фреймворк — сделал его понятнее и стабильнее;
- писал скрипты на C#, PowerShell и Python для подготовки данных и автоматизации рутины;
- разбирал падения тестов: логи, root cause, баг-репорты;
- выбирал, что автоматизировать, а что нет — с учётом того, что реально работает в продукте, а не в теории;
- переводил ручные проверки в автотесты, чтобы QA не делали одно и то же по 50 раз;
- настраивал CI/CD-пайплайны так, чтобы тестовый сигнал был полезным, а не шумом.

**Достижения:**
- вырос покрытие API-тестами со 117 до 199 — без увеличения времени прогона;
- срезал логи тестов с 1.5 ГБ до 11 МБ за запуск — падения стало находить за минуты, а не часы;
- ускорил setup тестов: часть подготовки данных перенёс с UI на API;
- сделал отчёты по тестам читаемыми — QA и разработчики перестали игнорировать результаты;
- участвовал в переходе на Playwright/TypeScript для Office.js-направления.
